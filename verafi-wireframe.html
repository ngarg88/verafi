What this is. A working front-end prototype of the agent harness: an ask-anything shopping agent, a Spend surface built on bank + merchant data, a Save surface where the agent recovers money, and a Pay surface that routes across the user's own cards, bank and wallet — holding no funds itself. The right panel exposes the harness: tool calls, rail selection, mandate evaluation and settlement events that would run against Plaid / Knot / AP2 / a PSP in production. Try: tap a suggested prompt, approve a purchase, then check Spend, Save and Pay. Name is a placeholder.
