Drop bank CSV / OFX / QFX exports in this folder.

Verafi watches it. Anything you drop here is imported automatically within a minute --
no dragging, no clicking, no import button. Duplicates are ignored, so you can re-drop
the same file or leave old ones here forever.

sample-statement.csv ships here so the app has something to show on first run.
Delete it once you've added your own -- it's fake data and it inflates your numbers.
